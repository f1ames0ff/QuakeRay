QuakeRay Portable Toolkit — Architecture (rev 6 · Goal A)

Goal A: standalone toolkit. QuakeRay owns the window, Vulkan device and swapchain; host adapters import another engine's data. The existing qray.h upload path is preserved; there is no monolithic QrayFrame and no second scene-transfer path. Geometry is read-only; the editor works on lighting, material and session data only. Embedded GPU (Goal B) is deferred.

Read the diagram left-to-right, top-to-bottom. Hosts feed the adapter; the adapter fills the three runtime contracts; the contracts call the existing qray.h upload API; lighting publishes cluster/DTAL lists; the RT core renders. The authoring column is the only mutable state: it writes a versioned sidecar, resolves identity, and applies intent through the same existing upload API.
